Política de privacidade

Última atualização: 4 de novembro de 2026

Resumo

O Estúdio roda só no computador do usuário. Não temos servidor, não coletamos dados e não compartilhamos nada com ninguém.

Quais dados o Estúdio usa

  • Autorização das contas: quando o usuário conecta o YouTube ou o TikTok, a plataforma entrega um código de acesso. Ele fica guardado só no computador do usuário e serve apenas para enviar os vídeos dele e ler os números desses vídeos.
  • Informações básicas da conta: o nome e o identificador da conta conectada (no TikTok, pelo escopo user.info.basic), usados só para mostrar "conectado como" e para não enviar vídeo para a conta errada.
  • Vídeos e textos: os vídeos, títulos e descrições que o próprio usuário cria e escolhe enviar (no TikTok, pelos escopos video.upload, para enviar como rascunho, e video.publish, para postar no perfil com as opções de privacidade e interação que o próprio usuário escolhe em cada post).

O que o Estúdio não faz

  • Não envia dados para servidores do Estúdio (não existem).
  • Não vende, aluga nem compartilha dados.
  • Não usa cookies, rastreamento nem publicidade.
  • Não lê mensagens, seguidores nem dados de outras pessoas.

Uso de dados das APIs do Google

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como apagar

O usuário pode revogar o acesso a qualquer momento em myaccount.google.com/permissions (Google) e nas configurações de segurança do app do TikTok. Apagar a pasta do programa e a pasta .animate do computador remove todos os dados guardados.
